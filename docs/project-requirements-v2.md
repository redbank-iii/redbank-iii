## 项目愿景

**让深空成像不再是少数机构的特权。**

- 用消费级传感器和开源设计, 把 Dragonfly 级别的深空成像能力从 $150,000 压到 $2,000
- 完全开源, 任何人都能造
- 1000 个中学生社团 > 1 个高端设备

---

## 核心设计决策

### 1. 单一技术路径 (无 Plan A/B)

**决策**: 只保留**手机改造方案**, 删除 IMX 模组方案 (Plan A)。

**理由**:
- 成本: $618 vs $1,600 (便宜 61%)
- 生态: Android 天文 app 现成, 白嫖 SoC + ISP
- 社区参与: 中学生能负担, 可复制

### 2. 传感器选择: IMX989 (手机)

**决策**: 选择 1" IMX989 (小米 12S Ultra 料板), 而非 IMX571 (APS-C) 或 IMX455 (全画幅)。

**理由**: 见 `why-imx989-phone-sensor.md`
- 天文学价值: 32 颗叠加后 SNR 接近 IMX571 阵列
- 社区参与: 唯一符合 "$2,000 以内" 宣言
- 中学生科研: 变星/小行星/超新星完全够用

### 3. 阵列规模: 32 镜 (8×4 网格)

**决策**: 32 个圆筒望远镜, 单一支架, 统一供电/控制。

**理由**:
- SNR 提升 √32 ≈ 5.7×
- 等效口径 382mm
- 成本可控 (32 × $618 = $19,776)

## 技术方案

### 单节点结构

```
天文镜头 (Samyang 135mm f/2.0, Sony E卡口)
    ↓
3D 打印底座/中框 (重新定位主板+sensor 模组)
    ↓
裸 CMOS (IMX989, 已拆除原镜头)
    ↓
手机主板 (原样不动, 排线连接)
    ↓
18650 电池包 / 统一 DC 供电
    ↓
USB ADB 控制
```

**关键**: PCB 和 sensor 模组**电气连接不动**, 只 3D 打印新底座重新定位。

### 阵列结构

- 32 个圆筒节点 (Ø80mm) 排成 8×4 网格
- 统一支架 + 赤道仪接口
- 统一供电 (18650 电池包 / 12V DC 母线)
- Mac mini 主控, USB ADB 集中控制

## 工程约束 (极客湾实测)

### ✅ 验证可行

1. **拆镜头** — 暴力拆除金属防滚架 + 外壳, 暴露裸 CMOS
2. **3D 打印中框** — 重新定位主板+模组, 让 sensor 光轴居中
3. **法兰距微调** — 螺丝 + 橡胶垫圈, 保证光学正常
4. **18650 供电** — 舍弃原电池, 只留保护板
5. **E卡口** — 闲鱼拆机件, 便宜易买

### ❌ 发现的坑

#### 1. Lens Shading (镜头阴影/偏色)

**问题**: 手机 ISP 算法针对原镜头一对一调校, 换镜头后矫枉过正。

**极客湾原话**:
> "手机的很多算法都无法直接套用在这种魔改方案上…这些算法反而会矫枉过正…直接拍出来的照片, 亮度和色彩均匀性都是很有问题的。"

**红岸三号对策**: 
- 拍 RAW, 放弃手机 ISP
- 自研平场校正 (flat-field) 管线
- 天文场景下可校正 (不像人像那么致命)

#### 2. 只能拍 RAW

**问题**: 换镜头后, 手机的 HDR/降噪/人像算法全部失效。

**极客湾原话**:
> "我们不得不拍RAW的照片, 放弃手机的一切软件优化算法, 在后期修图。"

**红岸三号对策**:
- **这正是我们要的** — 天文摄影本来就需要 RAW
- 自研叠加算法 > 手机 ISP
- 校正帧管线 (Bias/Dark/Flat) 是标准流程

#### 3. 卡口不严丝合缝

**问题**: 3D 打印底座 + 拆机卡口, 对准精度有限。

**极客湾原话**:
> "卡口的改装啊, 其实并不是很严丝合缝啊, 镜头和 CMOS 之间呢, 不见得是完全对准的。"

**红岸三号对策**:
- 校准台 (显微镜 + 位移台 + 平行光管)
- 每颗 sensor 校准 0.5–2 小时
- 一次性投入 ~¥1–4万

#### 4. 失去自动对焦

**问题**: 拆镜头后, 手机 AF 失效。

**极客湾实测**: 必须手动对焦。

**红岸三号对策**:
- **天文不需要 AF** — 星空全在无穷远
- 一次性装调后锁死, 不用反复对焦

## 开放问题与风险

### 高风险

1. **3D 打印精度** — 底座平面度/卡口同轴度能否稳定 hold 住法兰距 ±0.1mm + 倾斜 <0.05°
   - **缓解**: 关键配合面用 CNC 金属件
   
2. **Lens Shading 校正** — 平场校正能否完全修掉偏色
   - **缓解**: 实测验证, 天文场景下可校正

### 中风险

3. **MIPI 排线长度** — sensor 模组排线长度限制布局
   - **缓解**: 3D 打印底座设计时考虑排线走向

4. **ADB 并发稳定性** — 32 台同时 ADB 连接
   - **缓解**: 分批拉取 RAW, 或用 ADB over WiFi

5. **热噪声** — 手机无制冷, 长曝光热噪声
   - **缓解**: 短帧多叠 + 校正帧

### 低风险

6. **料板一致性** — 32 块同型号同批次
   - **缓解**: 统一采购小米 12S Ultra
